# Demon Chat Cam 🔥

Live camera + talk to horny demons (Incubus, Succubus, Shadow, Chaos).

## Run it live

1. **Easiest**: Open this preview (camera may need HTTPS):
   https://htmlpreview.github.io/?https://github.com/abcdt2438-beep/demon-chat-cam/blob/main/index.html

2. **Best (full camera)**: 
   - Go to your Netlify project: https://app.netlify.com/projects/demon-chat-cam
   - Drag & drop the `index.html` file, or connect this GitHub repo and deploy.
   - Then open https://demon-chat-cam.netlify.app

3. Or clone and open `index.html` in Chrome.

Allow camera → switch demons → talk dirty. The Incubus is waiting.
